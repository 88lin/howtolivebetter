# 广告配置与清理

当前版本不展示广告，也没有广告投放配置。

原站克隆时把推广区域作为页面 HTML 一起存进 `src/content/howtolivebetter/pages/*.json`；它们不来自广告 SDK、第三方广告服务、环境变量或单独的广告配置文件。清理前统计到 13,341 个组件实例：4,433 个页首位、4,433 个侧栏浮层、4,469 个页尾位和 6 个首页推广位。静态快照还包括六种语言的广告招租页，以及六种语言的合作品牌推广页。

`public/sites/howtolivebetter/styles/` 中的哈希 CSS 只包含这些区域的原站样式，没有广告投放逻辑。清理后相关页面节点、运行时代码、路由和专属品牌图片已移除；这些旧样式选择器不会生成或展示内容。

## 当前规则

- 广告组件使用 `life-ad-*` 类名或 `data-ad-*` 属性；页面导入器在转换 HTML 时跳过这些节点。广告布局包装器会被拆开，仅保留正文 `<main>`。
- 导入器忽略所有语言下以 `/advertise` 或 `/shengcaiyoushu` 结尾的路径，也不会从被忽略的推广链接重新发现它们。
- 运行 `npm run remove:advertising` 可幂等清理现有快照、路由索引和广告专用品牌素材。清理后的工作树会移除 12 个推广路由，普通内容路由不变。
- `npm run verify:no-advertising` 检查页面快照和推广路由没有重新出现；常规 CI 与 Pages 发布都会运行它。

文章、原书建议、商品清单和历史资料里提到“广告”的正文仍保留，因为它们是编辑内容，不是投放位。要添加未来广告时，需单独建立明确配置和展示策略；当前仓库没有此类配置入口。
